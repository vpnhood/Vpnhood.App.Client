NOTE: This app REQUIRES AN ACCESS KEY.

VpnHood! CLIENT is a fast, secure, and reliable VPN solution powered by the VpnHood! ENGINE, which is open-source and the first VPN developed fully with the .NET platform.

It is a client application that establishes encrypted, secure tunnels to a VPN server using the VpnHood protocol to VpnHood servers. With Cloak Mode, its traffic looks like ordinary web browsing, so the networks it crosses can hardly tell you use a VPN.

To use this app, an access key is required. You can acquire one through the following methods:

• Get access keys from friends or communities that distribute them.

• Purchase access keys for yourself or your friends from third-party sellers.

• Set up your own VpnHood server on a hosting service and create access keys yourself.

Customizable Options:

• Cloak Mode: Disguises your VPN traffic as regular web traffic, so the networks it crosses can hardly tell you use a VPN. That makes it resistant to deep packet inspection (DPI) and gets you past VPN blocks and network restrictions.

• Split Tunneling for Country: Keep traffic to your own country outside the tunnel, so local services that reject foreign IPs keep working and local connections stay fast.

• Split Tunneling for Domains: Choose which website addresses travel through the VPN tunnel and which stay outside it.

• Split Tunneling for IP Addresses: Include or exclude specific host IP addresses from VPN traffic.

• Split Tunneling for Local Network: Exclude your local network to maintain access to local resources while using VpnHood!.

• Custom DNS: Change the default DNS server by specifying your own.

• TCP, UDP & QUIC: Choose the transport protocol that performs best on your network.

• Proxy Support: Route your connection through SOCKS or HTTP proxies, entered manually or taken from your device settings.


Why Choose VpnHood!?

• Undetectable: Most VPNs hide what you do, but not that you use a VPN. VpnHood! looks like ordinary encrypted browsing, so your network can hardly tell, and DPI, firewalls and network restrictions have no VPN signature to catch.

• Constantly Evolving: VpnHood! keeps improving, so your connection stays private and keeps working on any network, even one that blocks VPNs.
