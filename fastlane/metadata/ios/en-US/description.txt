NOTE: This app REQUIRES A SERVER KEY.

VpnHood! CLIENT is a fast, secure, and reliable VPN solution powered by the VpnHood! ENGINE, which is open-source and the first VPN developed fully with the .NET platform.

It is a client application that establishes encrypted, secure tunnels to a VPN server using the VpnHood protocol to VpnHood servers. The VpnHood protocol has no fingerprint and cannot be detected by censorship filtering.

To use this app, a ServerKey is required. You can acquire one through the following methods:

▶ Get server keys from friends or communities that distribute them.

▶ Purchase server keys for yourself or your friends from third-party sellers.

▶ Set up your own VpnHood server on a hosting service and create server keys yourself.

Customizable Options:

• Cloak Mode: Disguises your VPN traffic as regular web traffic, making it resistant to deep packet inspection so the connection stays reliable on restricted networks.

• Split Tunneling for Country: Keep traffic to your own country outside the tunnel, so local services that reject foreign IPs keep working and local connections stay fast.

• Split Tunneling for Domains: Choose which website addresses travel through the VPN tunnel and which stay outside it.

• Split Tunneling for IP Addresses: Include or exclude specific host IP addresses from VPN traffic.

• Split Tunneling for Local Network: Exclude your local network to maintain access to local resources while using VpnHood!.

• Custom DNS: Change the default DNS server by specifying your own.

• TCP, UDP & QUIC: Choose the transport protocol that performs best on your network.

• Proxy Support: Route your connection through SOCKS or HTTP proxies, entered manually or taken from your device settings.
