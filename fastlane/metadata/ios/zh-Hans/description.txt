自定义选项：

• Cloak Mode：将 VPN 流量伪装成常规网页流量，有效抵御深度包检测，确保连接在受限网络中依然稳定。

• Split Tunneling for Country：将访问本国的流量留在隧道外，确保拒绝外国 IP 的本地服务正常运行，并保持本地连接高速。

• Split Tunneling for Domains：自主选择哪些网址走 VPN 隧道，哪些绕过隧道。

• Split Tunneling for IP Addresses：包含或排除特定的主机 IP 地址。

• Split Tunneling for Local Network：在使用 VpnHood! 时排除本地网络，以保持对本地资源的访问。

• Custom DNS：指定您自己的 DNS 服务器来更改默认设置。

• TCP, UDP & QUIC：选择在您的网络上表现最佳的传输协议。

• Proxy Support：通过手动输入或从设备设置获取的 SOCKS 或 HTTP 代理路由您的连接。
